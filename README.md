# Misi Kejujuran 3D

Permainan Pendidikan Moral bertema **Kejujuran** untuk murid sekolah rendah.

## Ciri utama
- Dunia kampung 3D menggunakan Three.js
- Pergerakan pemain menggunakan WASD, Arrow Keys atau butang sentuh
- Perjalanan sebenar dari satu lokasi ke lokasi lain dalam dunia 3D
- Anak panah petunjuk ke lokasi misi
- Rumah, jalan, pokok dan watak 3D
- 7 situasi moral berkaitan kejujuran
- Mata Kejujuran, objektif dan kemajuan 0/7 hingga 7/7
- Dialog, pilihan jawapan dan maklum balas
- Reka bentuk ringan untuk komputer sekolah dan telefon

## Teknologi
HTML, CSS, JavaScript dan Three.js.

## Menjalankan game
Projek ini direka untuk GitHub Pages. Three.js dimuatkan melalui jsDelivr.

## Nota
Objek asas dunia 3D dibina menggunakan geometry Three.js supaya projek ringan dan tidak memerlukan aset berlesen.
